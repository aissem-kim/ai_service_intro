B제공 형태별 유형

같은 AI 기능이라도 '누가, 어떻게' 쓰느냐에 따라 제공 형태가 나뉩니다. 취업·실무 관점에서 특히 중요한 구분입니다.

B-1앱 / 웹 서비스 (일반 사용자용)

웹사이트나 모바일 앱에서 바로 로그인해서 쓰는 형태입니다. 코딩 지식이 없어도 됩니다. 예: ChatGPT, Claude, Gemini, CLOVA X, 뤼튼.

B-2API (개발자용)

자신의 서비스·프로그램에 AI를 코드로 연동하는 형태입니다. 사용량만큼 요금을 내며, 백엔드 개발자가 다룹니다.

서비스제공사링크
OpenAI APIOpenAIplatform.openai.com
Anthropic API (Claude)Anthropicanthropic.com/api
Google AI Studio (Gemini API)Googleai.google.dev
CLOVA Studio네이버클라우드ncloud.com/.../clovaStudio
Upstage Console업스테이지console.upstage.ai
📌 앱 vs API 핵심 차이 — 앱은 완성된 화면을 쓰는 것이고, API는 AI 기능을 부품처럼 가져와 내 서비스에 끼워 넣는 것입니다. 채용 공고의 'LLM API 연동 경험'이 바로 이 영역입니다.

B-3파운데이션 모델 / 오픈 모델

서비스의 '엔진'이 되는 대규모 사전학습 모델 자체입니다. 일부는 가중치를 공개(오픈)하여 직접 내려받아 쓸 수 있습니다.

B-4클라우드 AI 플랫폼 (기업 인프라용)

기업이 보안·확장성을 갖춰 AI를 도입할 때 쓰는 형태입니다. 여러 회사의 모델을 한 플랫폼에서 골라 쓸 수 있습니다.
