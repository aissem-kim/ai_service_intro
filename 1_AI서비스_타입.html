AI서비스 유형

우리는 이미 하루에도 여러 번 AI서비스를 사용하고 있습니다.

  • 넷플릭스가 볼 영화를 추천해주고,
  • 스팸 메일함이 스스로 광고 메일을 걸러내고,
  • 번역 앱이 외국어 문장을 순식간에 옮겨줍니다.

이 강의는 실제 서비스 사례로 생성형·판별형 / 텍스트·이미지·음성·멀티모달 / 검색·추천·에이전트라는 세 가지 축을 하나씩 살펴보는 세션으로 구성됩니다.

SESSION // 0

강의 도입

지금 현실적으로 AI서비스의 종류가 너무 많습니다. 수백 개의 AI서비스를 세 가지 축(동작 방식 · 입출력 형태 · 기능)으로 정리하면, 처음 보는 서비스도 빠르게 분류할 수 있습니다.

아래 세 가지 축을 알면, 처음 보는 서비스도 "이건 생성형+이미지네", "이건 판별형+텍스트 기반 추천이네"처럼 빠르게 분류할 수 있습니다.

동작 방식 축

새로운 것을 "만드는가"(생성형), 아니면 "판단·분류하는가"(판별형)를 구분합니다.

입출력 형태 축

텍스트 / 이미지 / 음성 / 여러 형태를 동시에 다루는 멀티모달로 구분합니다.

기능 축

찾아주는 것(검색·추천), 대신 일해주는 것(에이전트·자동화)으로 구분합니다.

AI서비스란 무엇인가

"일반 소프트웨어와 무엇이 다른가요?" — AI서비스는 데이터를 학습한 모델이 확률적으로 판단한다는 점에서 정해진 규칙대로만 동작하는 전통 소프트웨어와 다릅니다.

▶

전통적인 소프트웨어는 개발자가 정한 규칙(if-then)대로만 동작합니다. 입력이 같으면 출력도 항상 같습니다. 반면 AI서비스는 데이터를 학습한 모델이 확률적으로 판단합니다. 즉 "정답"이 아니라 "가장 그럴듯한 답"을 내놓기 때문에 틀릴 수 있고, 사람이 규칙을 일일이 짜지 않아도 새로운 패턴에 대응할 수 있습니다.

비교표 ▶
구분전통 소프트웨어AI서비스
동작 방식개발자가 정한 규칙데이터로 학습한 모델
출력항상 동일(결정적)상황에 따라 달라짐(확률적)
예시 ARS AI챗봇
예시

은행 ARS

은행 ARS(전화 자동응답)의 "개인고객이면 1번을 누르세요" 방식은 규칙기반으로, 개인고객인 경우 서비스를 또 누르는 안내문이 나오고, 이에 해당하는 번호를 또 누르면서 정해진 응답을 듣습니다.

AI상담챗봇

SESSION // 2

두 개의 큰 축: 생성형 vs 판별형

"만드는 AI와 판단하는 AI" — 생성형은 새로운 결과물을 만들어내고, 판별형은 주어진 것에 대해 판단합니다. 실제 서비스는 두 방식을 함께 쓰는 경우가 많습니다.

▶

생성형(Generative) AI는 학습 데이터에서 익힌 패턴을 조합해 새로운 결과물(텍스트, 이미지, 음성, 코드 등)을 만들어냅니다. 판별형(Discriminative) AI는 입력이 주어졌을 때 "이것은 무엇인가/어느 범주인가"를 판단·분류·예측합니다. (예: AI이력서 첨삭 서비스는 문제점을 판별하고, 수정문을 생성합니다.)

— "무(無)에서 창작한다"는 표현은 정확하지 않습니다. 생성형AI는 학습한 방대한 데이터의 통계적 패턴에서 새로운 조합을 만들어내는 것입니다. 그래서 학습 데이터에 없던 개념은 잘 못 만들고, 그럴듯하지만 사실이 아닌 내용을 만들어내는 환각(hallucination)이 발생합니다.
예시

ChatGPT / Claude

생성형

질문에 대한 답변 문장을 새로 생성합니다.

Suno

생성형

가사만 넣으면 새 노래를 생성합니다.

Gmail 스팸 필터

판별형

메일이 스팸인지 아닌지 분류합니다.

신용카드사 이상거래 탐지

판별형

정상/이상 거래를 판별합니다.

채용 서류 AI스크리닝

판별형

지원자 서류를 분류·점수화합니다. 다만 AI가 단독으로 합격/불합격을 결정하는 방식은 각국에서 규제 대상이며(EUAIAct는 채용·인사AI를 고위험으로 분류), 실무에서는 사람의 검토를 거치는 보조 수단으로 씁니다.

구분생성형AI판별형AI

실습문제
  1. 다음 서비스를 생성형/판별형으로 분류하세요: ① 파파고 번역 ② 카드사 부정거래 탐지 시스템 ③ Midjourney 이미지 생성 ④ 의료 영상에서 종양 여부 판독AI ⑤ AI이력서 자동 첨삭
  2. (사례 매칭) "우리 회사 게시판에 올라오는 욕설/스팸 댓글을 자동으로 걸러내고 싶다"는 요구사항이 있다면, 생성형과 판별형 중 어떤 접근이 필요한지 근거와 함께 설명하세요.
  3. 생성형과 판별형을 모두 사용하는 서비스를 하나 골라, 각각 어느 부분에서 쓰이는지 나눠 설명해보세요.
정답 ▶

1. ① 파파고 번역 — 생성형 ② 부정거래 탐지 — 판별형 ③ Midjourney — 생성형 ④ 종양 여부 판독 — 판별형 ⑤ AI 이력서 자동 첨삭 — 생성형.

2. 판별형이 먼저입니다. "걸러낸다"는 것은 욕설/스팸 여부를 판단·분류하는 문제이기 때문입니다. 문구를 대신 써주는 것(생성형)은 이 요구사항의 핵심이 아닙니다.

3. 예시 — AI 이력서 첨삭 서비스: 문제점을 찾아내는 부분은 판별형, 수정 문장을 만들어주는 부분은 생성형입니다. (물류라면 클레임 처리: 파손 여부 판정은 판별형, 고객 안내문 작성은 생성형)

텍스트AI서비스

"챗봇·요약·번역·작문" — 사람의 언어를 이해하고 생성하는 서비스로, 서비스가 어떤 목적에 특화되어 있는지가 유형 구분의 기준입니다.

텍스트AI는 사람의 언어(자연어)를 이해하고 생성하는 서비스로, 크게 네 갈래로 나뉩니다: 대화(챗봇), 요약, 번역, 작문/교정. 내부적으로는 대부분 대규모 언어모델(LLM)을 기반으로 합니다.

예시

챗봇/대화 — ChatGPT, Claude

고객상담 자동응답, 사내 지식 Q&A 봇

요약 — NotionAI, ChatGPT, Claude

회의를 직접 녹음·전사한 뒤 요약까지 하는 도구(NotionAI회의록, ChatGPT 레코드 모드 ·Mac 앱·유료 플랜 전용, Windows/웹 미지원)와, 이미 글로 옮겨진 내용(전사본·문서·기사)을 넣어야 요약하는 도구(Claude)로 나뉩니다.

번역 — 파파고, DeepL, 구글번역

해외 고객 응대, 다국어 제품 설명

작문/교정 — Grammarly, 뤼튼

마케팅 문구 초안 작성, 이메일 교정, 자기소개서 문장 다듬기

실무 시나리오 — 이커머스 고객센터에서는 챗봇(1차 문의 응대) + 요약(상담 내용 티켓 정리) + 번역(해외 고객 대응)을 함께 조합해 운영하는 경우가 많습니다.
비교표 ▶
세부유형입력출력주 활용 산업
챗봇사용자 질문답변 문장유통, 금융 고객센터
요약긴 텍스트(문서·전사본)
음성은 STT로 변환한 뒤 요약(세션 5)		짧은 핵심 요약언론, 법률, 교육
번역원문 텍스트번역 텍스트무역, 여행, 글로벌 서비스
작문/교정키워드/초안완성 문장마케팅, HR(자소서 첨삭)
실습문제
  1. 다음 업무 요청에 어떤 세부 유형(챗봇/요약/번역/작문)이 필요한지 매칭하세요: ① "해외 리뷰 500개를 한국어로 바꿔줘" ② "3시간짜리 회의 녹취록을 한 페이지로 정리해줘" ③ "자소서 문장을 더 매끄럽게 다듬어줘" ④ "24시간 고객 문의에 응답해줘"
  2. 여러분이 지원하고 싶은 회사의 채용공고를 하나 떠올리고, "텍스트AI서비스"가 그 직무/산업에서 어떻게 쓰일 수 있을지 2가지 이상 제안해보세요.
정답 ▶

1. ① 번역 ② 요약 ③ 작문/교정 ④ 챗봇.

2. (제안 예시) 채용공고에 "고객 문의 응대"가 있다면 챗봇으로 1차 응대를, "보고서 작성"이 있다면 요약·작문으로 초안 작성 시간을 줄이는 식으로, 직무의 반복 작업을 텍스트 AI의 세부 유형과 하나씩 짝지어 설명하면 됩니다.

SESSION // 3-2

이미지AI서비스

"생성 / 인식 / 편집" — 생성은 대표적인 생성형AI이고, 인식은 대표적인 판별형AI라는 점에서 세션 2의 축과 바로 연결됩니다.

이미지AI는 세 갈래로 나뉩니다: 없던 이미지를 만드는 생성, 이미지 속 내용을 파악하는 인식, 기존 이미지를 다듬거나 바꾸는 편집.

예시

생성 — Midjourney, ChatGPT 이미지 생성, Stable Diffusion

광고 시안 제작, 게임 컨셉아트

인식 — 안면인식, 자율주행 객체 탐지

보안 출입관리, 자율주행차

인식(OCR) — 클로바 OCR, 구글 렌즈

영수증/명함 자동 입력, 문서 디지털화

편집 — Photoshop 생성형 채우기, Remove.bg

제품사진 배경제거, 사진 합성

비교표 ▶
세부유형생성형/판별형대표 서비스대표 산업
생성생성형Midjourney광고, 게임, 디자인
인식(안면/사물)판별형안면인식 게이트보안, 유통(무인매장)
인식(OCR)판별형클로바 OCR금융(서류처리), 물류
편집생성형+판별형 혼합Remove.bg, 포토샵AI이커머스, 마케팅
실습문제
  1. 다음을 생성/인식/편집으로 분류하세요: ① 명함 사진을 찍으면 자동으로 연락처가 저장되는 기능 ② 텍스트 설명만으로 광고 이미지를 만드는 기능 ③ 인물 사진에서 배경만 지우는 기능 ④ CCTV에서 특정 인물을 찾아내는 기능
  2. 무인 편의점을 운영한다고 가정할 때, 이미지AI를 활용할 수 있는 지점을 2가지 이상 제안하세요(어떤 세부 유형인지 명시).
  3. (사례 매칭) 온라인 쇼핑몰 MD가 "제품 사진 촬영 비용을 줄이고 싶다"고 할 때, 어떤 이미지AI서비스를 제안하겠습니까?
정답 ▶

1. ① 인식(OCR) ② 생성 ③ 편집 ④ 인식.

2. (제안 예시) 진열대 재고 인식(인식 — 상품이 비었는지 카메라로 판단), 계산대 없는 결제를 위한 손동작·상품 인식(인식), 프로모션 배너 이미지 자동 생성(생성) 등 두 가지 이상을 세부 유형과 함께 짝지으면 됩니다.

3. (답안 방향) 생성형 이미지 AI(예: Midjourney류)로 텍스트 설명만으로 제품 배경/연출 이미지를 만들거나, Remove.bg류의 편집 AI로 촬영한 사진의 배경만 자동으로 바꿔 촬영 비용을 줄이는 방향을 제안하면 됩니다.

음성AI서비스

"STT / TTS / 음성비서" — 음성비서는 텍스트AI(챗봇)와 음성 기술(STT/TTS)이 결합된 사례로, 여러 유형의 조합을 처음 체감하는 세션입니다.

핵심 개념 3가지

STT (Speech-to-Text)

음성을 텍스트로 변환합니다.

TTS (Text-to-Speech)

텍스트를 자연스러운 음성으로 변환합니다.

음성비서

STT + 언어이해 + 응답생성 + TTS가 결합된 종합 서비스(예: 시리, 빅스비)

예시

STT — 네이버 클로바노트, Whisper

회의/강의 자동 받아쓰기, 상담 통화 기록

TTS — 네이버 클로바더빙, ElevenLabs

오디오북 제작, 안내방송 음성 생성

음성비서 — 시리, 빅스비, 기가지니

스마트폰/스마트스피커 음성 명령 처리

비교표 ▶
세부유형입력출력대표 산업
STT음성텍스트콜센터(상담 기록), 교육(강의 자막)
TTS텍스트음성미디어(더빙), 접근성(시각장애인 지원)
음성비서음성 명령음성/행동 응답가전, 모바일, 자동차
실습문제
  1. 다음 업무에 STT/TTS 중 무엇이 필요한지 답하세요: ① 상담원 통화 내용을 텍스트로 자동 기록 ② 웹소설을 오디오북으로 변환 ③ 유튜브 영상에 자동 자막 생성
  2. 콜센터에 음성AI를 도입한다면, STT와 TTS를 각각 어느 단계에 적용할지 시나리오를 짜보세요(상담 접수 → 처리 → 안내까지).
  3. (오답 찾기) "음성비서는 TTS 기술 하나만으로 동작한다" — 이 문장의 문제점을 설명하세요.
정답 ▶

1. ① STT ② TTS ③ STT.

2. (시나리오 예) 접수 — 고객 음성을 STT로 실시간 기록·검색 가능한 텍스트로 변환 → 처리 — 텍스트로 유형 분류·상담사 배정 → 안내 — 처리 결과를 TTS로 자동 음성 안내(ARS)에 반영.

3. 음성비서는 사용자의 말을 알아듣는 STT, 의도를 파악하는 언어이해, 응답을 만드는 생성, 이를 말로 바꾸는 TTS가 모두 결합된 서비스입니다. TTS만으로는 "듣고 이해하는" 부분이 없어 비서 역할을 할 수 없습니다.

SESSION // 3-4

멀티모달AI서비스

"보고 듣고 읽는 AI" — 텍스트·이미지·음성·영상 등 여러 형태의 정보를 동시에 이해하거나 생성합니다.

지금까지 배운 텍스트/이미지/음성AI가 "한 가지 감각"만 다뤘다면, 멀티모달은 사람처럼 여러 감각을 결합해 판단합니다.

흔한 오해 — "번역 앱은 텍스트만 다루니까 단일모달"이라고 생각하기 쉽지만, 파파고·구글 번역은 이미 카메라 번역(이미지)·음성 번역·필기 번역을 지원하는 멀티모달 서비스입니다. 서비스 이름이 아니라 그 기능이 어떤 입력을 받는지로 판단해야 합니다.
예시

ChatGPT, Claude, Gemini

사진을 보여주며 "이 그래프 내용을 설명해줘"라고 텍스트로 질문하면, 이미지+텍스트를 함께 이해해 답변합니다.

회의 영상 자동 요약 서비스

화면(슬라이드)과 음성(발언 내용)을 동시에 분석해 회의록을 생성합니다.

자율주행차

카메라(이미지)+라이다·레이더(거리·공간정보)+GPS 등 서로 다른 종류의 센서 데이터를 하나로 합쳐 판단합니다.

비교표 ▶
구분단일모달AI멀티모달AI
처리 형태텍스트만, 이미지만 등 하나텍스트+이미지+음성 등 복합
예시Gmail 스팸 필터(텍스트만), Remove.bg(이미지만)ChatGPT·Gemini(텍스트+이미지+음성)
활용단순 반복 업무복합적 판단이 필요한 업무
실습문제
  1. 다음 중 멀티모달AI 활용 사례를 고르세요: ① 사진 속 표를 보고 텍스트로 분석해주는 AI ② 텍스트만 입력받아 번역하는 AI ③ 화면 녹화+음성 설명을 함께 이해해 회의록을 만드는 AI
  2. 여러분의 전공/관심 분야에서 멀티모달AI가 유용할 수 있는 업무를 하나 설계해보세요(어떤 감각 정보를 조합하는지 명시).
  3. (면접형) "왜 멀티모달AI가 최근 중요해지고 있다고 생각하나요?"에 대한 답변을 준비해보세요.
정답 ▶

1. ① 과 ③ 입니다. ①은 이미지+텍스트, ③은 영상(이미지)+음성을 함께 이해하므로 멀티모달입니다. ②는 텍스트만 다루므로 단일모달입니다.

2. (설계 예) 어떤 업무인지, 그리고 텍스트/이미지/음성 중 몇 가지 형태의 정보를 함께 결합하는지가 답안에 명확히 드러나면 됩니다.

3. (답안 방향) 실제 데이터는 원래 텍스트·이미지·음성이 섞여 있고, 한 가지 감각만 보면 판단이 부정확해지기 쉽습니다. 최근 모델 성능과 비용이 여러 형태를 동시에 처리할 수 있을 만큼 발전해, 사람처럼 종합적으로 판단하는 서비스가 늘고 있다는 점을 답변에 포함하면 좋습니다.

▶
SESSION // 4-1

검색·추천·임베딩 서비스

"찾아주고 골라주는 AI" — 무언가를 새로 만들기보다 이미 있는 것 중에서 고르는 쪽에 가까우며, 이커머스·미디어 기업의 핵심 수익 모델과 직결됩니다.

핵심 개념 2가지

[비교] 기존 검색

기존에는 단어가 일치하는 것을 결과로 찾아줍니다.

임베딩 (Embedding)

텍스트/이미지 등을 "의미 기준으로 비교"할 수 있도록 숫자 벡터로 바꾸는 기술입니다.

추천

사용자의 과거 행동/취향 데이터를 바탕으로 관련 항목을 골라줍니다.

예시

임베딩 기반 검색

"결제 오류"로 검색해도 "정산 실패" 문서를 찾아줍니다.

추천 — 유튜브, 넷플릭스, 쿠팡

시청/구매 이력 기반 맞춤 콘텐츠·상품을 제시합니다.

추천+검색 결합 — "함께 본 상품"

클릭 로그 기반 연관 상품을 추천합니다.

비교표 ▶
구분목적대표 서비스대표 산업
임베딩 검색의미 기반으로 찾기사내 지식검색, RAG 챗봇기업 내부 시스템, 고객지원
추천개인화된 항목 제시유튜브, 넷플릭스미디어, 이커머스
실습문제
  1. "환불"이라고 검색했는데 "반품"이라는 단어가 들어간 문서까지 찾아준다면, 이것이 왜 "임베딩 기반 검색"의 예시인지 설명하세요.
  2. 여러분이 자주 쓰는 서비스에서 "추천" 기능을 하나 찾아, 어떤 데이터를 기반으로 추천이 이뤄지는지 추측해보세요.
  3. (사례 매칭) 사내 문서가 수만 건 있는 회사에서 직원들이 원하는 문서를 빨리 못 찾는다는 문제가 있다면, 어떤 AI서비스 유형을 제안하겠습니까?
정답 ▶

1. "환불"과 "반품"은 글자가 다르지만 의미가 비슷합니다. 임베딩 검색은 단어 일치가 아니라 의미(벡터 거리)로 비교하므로, 동의어·유사 개념 문서까지 찾아줍니다. 이것이 기존 단어 일치 검색과의 차이입니다.

2. (추측 예) 유튜브·넷플릭스라면 시청 이력·평점·클릭 로그, 쇼핑몰이라면 구매·장바구니·찜 이력이 추천의 기반 데이터가 됩니다.

3. 임베딩 기반 사내 지식검색(사내 RAG 챗봇)을 제안합니다. 직원이 정확한 단어를 몰라도 의미가 비슷한 문서를 찾아주기 때문입니다.

SESSION // 4-2

AI에이전트 & 자동화 서비스

"스스로 일하는 AI" — 지금까지 배운 텍스트/이미지/음성/검색AI가 "재료"라면, 에이전트는 이를 조합해 업무 흐름을 대신 처리하는 "완성품"입니다.

AI에이전트는 사람이 매 단계 지시하지 않아도, 목표만 주어지면 스스로 계획하고, 여러 도구를 순서대로 사용해 작업을 완료하는 서비스입니다.

예시

ZapierAI / Make

"이메일 도착 → 내용 요약 → 슬랙에 전달"처럼 여러 앱을 연결해 자동 처리합니다.

AI회의 비서 (클로바노트, Otter.ai)

회의 녹음 → 자동 받아쓰기 → 요약·액션아이템 정리까지 수행합니다. 메일 발송 등 후속 조치는 별도 자동화 도구와 연결해야 합니다.

사내 업무 자동화 봇

"매주 월요일 매출 데이터 취합 → 보고서 작성 → 팀장에게 전송"을 자동 반복합니다.

비교표 ▶
구분일반AI서비스AI에이전트
동작한 가지 요청에 한 번 응답목표를 주면 여러 단계를 스스로 계획·실행
예시"이 문서를 요약해줘""매주 이 문서들을 모아 요약하고 담당자에게 보내줘"
활용 산업전 산업 공통반복 업무가 많은 모든 부서(HR, 마케팅, 운영)
실습문제 (종합 실습)
  1. 다음 업무를 자동화하려면 어떤 AI서비스들을 어떤 순서로 조합해야 할지 설계해보세요: "매일 아침 뉴스에서 우리 회사 관련 기사를 찾아, 한국어로 요약하고, 팀 슬랙 채널에 올리기"
  2. 여러분이 지금 아르바이트/인턴 업무 중 반복적으로 하는 일 하나를 떠올리고, 오늘 배운 세션 중 무엇을 조합하면 자동화할 수 있을지 설계해보세요.
  3. (면접형) "AI에이전트와 일반 챗봇의 차이가 무엇인가요?"라는 질문에 답변을 작성해보세요.
정답 ▶

1. ① 뉴스에서 회사 관련 기사 검색(도구 호출/검색) → ② 관련 기사인지 판별·선별(판별형) → ③ 한국어로 요약(텍스트 AI, 생성형) → ④ 슬랙에 자동 게시(자동화 도구 연결). 이 순서가 드러나면 됩니다.

2. (설계 예) "반복 업무 → 어떤 유형의 AI가 필요한지 → 어느 단계에 사람 확인이 필요한지"가 순서대로 정리되면 좋은 답입니다.

3. 일반 챗봇은 질문 하나에 답 하나를 주는 데 그치지만, AI 에이전트는 목표만 주어지면 스스로 여러 단계를 계획하고 여러 도구를 순서대로 사용해 작업을 끝까지 수행합니다.

실제 물류 시스템에 적용한다면

물류는 AI를 붙이기 좋은 산업입니다. AI 유형을 스스로 찾아봅니다.

▶

각 세션마다 짚었던 [ 참고 ] 물류 보강 내용을 여기 한 곳에 모았습니다. 아래 세션 제목을 클릭하면 해당 세션과 이어지는 물류 사례가 펼쳐집니다.

물류 현장의 음성AI — 손과 눈이 이미 바쁜 환경

세부유형물류 업무 예문왜 물류에서 중요한가
STT관제-차주 통화, 콜센터 상담 자동 기록구두 합의가 분쟁의 원인이 됨 → 기록이 곧 증거
STT기사 음성 메모("3층 부재, 경비실 인계")를 텍스트 필드로 변환운행 중에는 타이핑이 불가능
음성 피킹헤드셋으로 "A-12-3 로케이션, 3개" 안내 → 작업자가 "확인" 응답손이 자유로워야 하는 대표 업무. 스캐너를 들었다 놓는 동작이 사라짐
TTS배송 예정 자동 안내 콜, 창고 안전 방송다국어 안내가 필요한 현장에서 특히 유용
음성비서차량 내 핸즈프리 "다음 배송지 알려줘"운전 중 조작은 안전 문제와 직결
한계 — 창고·차량은 소음이 크고 사투리·약어가 섞입니다. 시연할 때 일부러 시끄러운 환경 녹음을 들려주고 인식률이 떨어지는 것을 보여주면 "AI는 조건이 맞아야 성능이 난다"는 감각이 생깁니다.

물류의 멀티모달 — "물건을 못 받았다" 신고 1건

물류 현장의 판단은 원래부터 멀티모달입니다. 분쟁 하나를 처리할 때 담당자는 사진을 보고, 좌표를 확인하고, 메모를 읽고, 통화를 듣습니다. 사람이 이미 그렇게 하고 있다는 점을 짚으면 개념이 쉽게 이해됩니다.

입력 정보형태AI가 확인하는 것
배송완료 사진이미지현관 형태, 문패·호수, 물건이 실제로 놓여 있는지
배송 시각 GPS 좌표수치·위치사진 위치와 배송지 주소의 일치 여부
기사 메모텍스트"경비실 인계" 같은 예외 처리 여부
고객 통화 녹취음성주장 내용과 위 기록의 모순 지점
문장 — 네 가지를 따로 보면 판단이 안 되고 합쳐야 결론이 납니다. 이것이 멀티모달이 필요한 이유입니다. 단, 최종 보상 결정은 사람이 합니다.

견적 자동화

화물 사진 + "냉장, 파렛트 2개, 부산→인천" 텍스트를 함께 넣으면 적정 차종·포장·운임 범위를 제안합니다.

창고 안전 관제

CCTV 영상 + 설비 센서값 + 알람 소리를 결합해 이상 상황을 판단합니다.

창고 로봇

카메라·라이다·위치 정보를 합쳐 자율주행 지게차(AFL)와 이송로봇(AGV)이 이동합니다.

물류의 검색·추천 — 그리고 "배차는 챗봇이 아니다"

물류는 규정과 예외가 많은 산업입니다. 위험물 취급 기준, 통관 요건, 항공·해상 운송 제한, 사고 처리 SOP, 화주사별 특약이 전부 문서로만 존재하고 신입은 어디 있는지 모릅니다.

구분내용
A. 사내 규정 검색
(임베딩·RAG)		문서에 정확한 단어가 없어도, 의미가 비슷한 규정 문서를 찾아줍니다.
B. 매칭·추천화물↔차량 배차 추천, 유사 클레임 사례 검색, 물량이 몰릴 때 대체 거점 추천.
C. "AI = LLM"이 아니다배차·경로 문제는 챗봇이 아니라 제약조건 최적화로 풉니다. 적재중량, 도착 시간창, 기사 근로시간, 유류비, 회차 지점을 동시에 만족시켜야 하기 때문입니다.
예문 : 신입이 "리튬배터리 들어간 제품, 항공으로 보낼 수 있나요?"라고 물으면, 문서에 "리튬"이라는 단어가 없어도 "UN3481 / 이차전지 / 위험물 등급" 문서를 찾아옵니다. 이것이 단어 일치 검색과의 차이입니다.
국내 사례 — 위밋모빌리티의 배차·경로 최적화 시스템은 제약 프로그래밍(CP) 기반 모델을 쓰며 국토교통부 우수 물류신기술 제9호로 지정되었습니다(투입 차량 약 15% 감소, 차량별 이동거리 약 18% 감소로 보도).
문장 — "생성형AI가 유행이라고 모든 문제를 챗봇으로 풀려 하면 안 됩니다. 배차는 글을 쓰는 문제가 아니라 숫자를 맞추는 문제입니다." 인턴이 AI도입 제안에서 가장 흔히 하는 실수를 미리 막아 줍니다.
